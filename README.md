# University Pre-Admission Help System

A professional university admission portal developed using JSP, JDBC, MySQL, and Apache Tomcat.

## Features
- Dynamic Programme List
- Contact Query System
- Database Connectivity using JDBC
- Modern Responsive UI
- JSP + MySQL Integration

## Technologies Used
- Java JSP
- JDBC
- MySQL
- Apache Tomcat
- HTML
- CSS
